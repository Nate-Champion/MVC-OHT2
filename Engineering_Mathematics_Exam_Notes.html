9.1 Simple Vectors

1. What is a vector?

A scalar has magnitude only. A vector has magnitude and direction.

ScalarVector
Mass, temperature, timeVelocity, force, displacement
Written as a numberWritten using components or an arrow

2. Component form

In 3D, a vector is usually written:

𝐀 = Ax𝐢 + Ay𝐣 + Az𝐤 = ⟨Ax, Ay, Az⟩

where 𝐢, 𝐣, 𝐤 are unit vectors along x, y, z.

3. Magnitude / length

|𝐀| = √(Ax2 + Ay2 + Az2)
Example: Find the magnitude of 𝐀 = 3𝐢 − 4𝐣 + 12𝐤.
|𝐀| = √(3² + (−4)² + 12²)
= √(9 + 16 + 144) = √169 = 13

4. Unit vector

A unit vector has magnitude 1 and points in the same direction as the original vector.

𝐀̂ = 𝐀 / |𝐀|
Example: 𝐀 = 3𝐢 + 4𝐣. Then |𝐀| = 5, so
𝐀̂ = (3/5)𝐢 + (4/5)𝐣

5. Adding and subtracting vectors

𝐀 ± 𝐁 = ⟨Ax ± Bx, Ay ± By, Az ± Bz⟩
Example: 𝐀 = ⟨2,−1,3⟩ and 𝐁 = ⟨4,2,−1⟩.
𝐀 + 𝐁 = ⟨6,1,2⟩
𝐀 − 𝐁 = ⟨−2,−3,4⟩
Exam tip: Always separate the i, j, k components. Most vector arithmetic is just component-by-component arithmetic.

9.2 Dot Product

1. Definition

The dot product (scalar product) of two vectors produces a scalar.

𝐀 · 𝐁 = AxBx + AyBy + AzBz

2. Geometric formula

𝐀 · 𝐁 = |𝐀||𝐁| cos θ

Therefore:

cos θ = (𝐀 · 𝐁)/(|𝐀||𝐁|)

3. Perpendicular vectors

If two nonzero vectors are perpendicular, θ = 90°, so cos 90° = 0.

𝐀 ⟂ 𝐁 ⇔ 𝐀 · 𝐁 = 0
Example: Determine whether 𝐀 = ⟨1,2,3⟩ and 𝐁 = ⟨2,−1,0⟩ are perpendicular.
𝐀 · 𝐁 = (1)(2) + (2)(−1) + (3)(0)
= 2 − 2 + 0 = 0
Therefore, 𝐀 and 𝐁 are perpendicular.

4. Angle between vectors

Example: Find the angle between 𝐀 = 𝐢 + 𝐣 and 𝐁 = 𝐢 − 𝐣.
𝐀 · 𝐁 = 1(1)+1(−1)=0
Therefore cos θ = 0.
θ = 90°.

5. Projection / scalar component

The scalar component of 𝐀 in the direction of 𝐁 is:

comp𝐁𝐀 = (𝐀 · 𝐁)/|𝐁|

The vector projection is:

proj𝐁𝐀 = [(𝐀 · 𝐁)/|𝐁|²]𝐁
Common mistake: Dot product gives a scalar, not a vector. If your final answer still contains i, j, k, you probably did not finish a dot product.

9.3 Cross Product

1. What does it do?

The cross product of two vectors produces a vector perpendicular to both vectors.

𝐀 × 𝐁 = |𝐀||𝐁| sin θ 𝐧̂

where 𝐧̂ is the unit vector perpendicular to the plane containing 𝐀 and 𝐁.

2. Determinant method

𝐀 × 𝐁 = | 𝐢 𝐣 𝐤 |
| Ax Ay Az |
| Bx By Bz |

Expanded:

𝐀 × 𝐁 = (AyBz − AzBy)𝐢 − (AxBz − AzBx)𝐣 + (AxBy − AyBx)𝐤
Example: Find 𝐀 × 𝐁 for 𝐀 = ⟨1,2,3⟩, 𝐁 = ⟨4,5,6⟩.
i: 2(6) − 3(5) = 12 − 15 = −3
j: −[1(6) − 3(4)] = −(6 − 12) = +6
k: 1(5) − 2(4) = 5 − 8 = −3
𝐀 × 𝐁 = ⟨−3,6,−3⟩

3. Direction / right-hand rule

  • Point your index finger along 𝐀.
  • Point your middle finger along 𝐁.
  • Your thumb gives the direction of 𝐀 × 𝐁.

4. Important properties

𝐀 × 𝐁 = −(𝐁 × 𝐀)
𝐀 × 𝐀 = 0
𝐀 × 𝐁 = 0 ⇔ 𝐀 and 𝐁 are parallel (or one is zero)

5. Area

Area of the parallelogram formed by 𝐀 and 𝐁:

Area = |𝐀 × 𝐁|

Area of the triangle:

Area = ½|𝐀 × 𝐁|
Most common cross-product trap: The j-component gets a minus sign in determinant expansion.

9.4 Divergence

For a vector field, divergence measures the net tendency of the field to spread out from or converge toward a point.

1. Vector field

𝐅(x,y,z) = P(x,y,z)𝐢 + Q(x,y,z)𝐣 + R(x,y,z)𝐤

2. Divergence formula

∇ · 𝐅 = ∂P/∂x + ∂Q/∂y + ∂R/∂z

Notice the pattern: differentiate each component with respect to its matching variable.

Example: Find div 𝐅 for 𝐅 = x²y𝐢 + 3yz²𝐣 + 5xz𝐤.
P = x²y → ∂P/∂x = 2xy
Q = 3yz² → ∂Q/∂y = 3z²
R = 5xz → ∂R/∂z = 5x
∇·𝐅 = 2xy + 3z² + 5x

3. Physical intuition

DivergenceMeaning
∇·𝐅 > 0Net source / field spreading outward
∇·𝐅 < 0Net sink / field converging inward
∇·𝐅 = 0No net local spreading; called divergence-free or solenoidal
Memory trick: DIV = “same letter underneath”: P with x, Q with y, R with z.

9.6 Partial Derivatives & Euler's Theorem

1. What is a partial derivative?

If a function has several independent variables, a partial derivative measures change with respect to one variable while keeping the others constant.

z = f(x,y)
fx = ∂f/∂x     fy = ∂f/∂y
Example: z = x³y² + 4xy + y³.
With respect to x: treat y as constant.
zx = 3x²y² + 4y
With respect to y: treat x as constant.
zy = 2x³y + 4x + 3y²

2. Second-order partial derivatives

fxx = ∂²f/∂x²,   fyy = ∂²f/∂y²,   fxy = ∂²f/(∂y∂x)
Example: f(x,y)=x²y³.
fx=2xy³
fxx=2y³
fy=3x²y²
fyy=6x²y
fxy=6xy²
Useful fact: For sufficiently smooth functions, mixed partials are equal: fxy = fyx.

3. Homogeneous functions

A function f(x,y) is homogeneous of degree n if:

f(tx,ty) = tn f(x,y)

Examples:

  • x² + xy + y² is homogeneous of degree 2.
  • x³ + x²y + y³ is homogeneous of degree 3.
  • x² + y is not homogeneous because the terms have different degrees.

4. Euler's theorem for homogeneous functions

If f(x,y) is homogeneous of degree n:

x fx + y fy = n f

For three variables:

x fx + y fy + z fz = n f
Example: Verify Euler's theorem for f(x,y)=x²+xy+y².
This is homogeneous of degree n=2.
fx=2x+y;   fy=x+2y
x fx + y fy = x(2x+y)+y(x+2y)
= 2x²+2xy+2y²
= 2(x²+xy+y²) = 2f
Exam check: Before using Euler's theorem, verify that the function is homogeneous and identify its degree.

9.7 Directional Derivatives

1. What does it mean?

The directional derivative tells you the rate at which a scalar function changes in a specified direction.

2. Gradient

For f(x,y,z), the gradient is:

∇f = fx𝐢 + fy𝐣 + fz𝐤

In 2D:

∇f = fx𝐢 + fy𝐣

The gradient points in the direction of maximum increase of f.

3. Directional derivative formula

D𝐮f = ∇f · 𝐮

where 𝐮 must be a unit vector.

4. The 4-step method ⭐

  1. Find ∇f.
  2. Find the direction vector 𝐯.
  3. Convert it to a unit vector: 𝐮 = 𝐯/|𝐯|.
  4. Calculate D𝐮f = ∇f · 𝐮.
Example: Find the directional derivative of f(x,y)=x²+3xy+y² at (1,2) in the direction from (1,2) to (4,6).
Step 1: Gradient
∇f = ⟨2x+3y, 3x+2y⟩
Step 2: Evaluate at (1,2)
∇f(1,2)=⟨2+6,3+4⟩=⟨8,7⟩
Step 3: Direction vector
𝐯 = ⟨4−1,6−2⟩ = ⟨3,4⟩
Step 4: Unit vector
|𝐯|=5, so 𝐮=⟨3/5,4/5⟩
Step 5: Dot product
D𝐮f = ⟨8,7⟩·⟨3/5,4/5⟩ =24/5+28/5 =52/5

5. Maximum directional derivative

The maximum possible directional derivative at a point is:

max D𝐮f = |∇f|

It occurs in the direction:

𝐮 = ∇f / |∇f|

6. Minimum directional derivative

min D𝐮f = −|∇f|

and it occurs in the direction opposite to the gradient.

7. Direction of zero change

If 𝐮 is perpendicular to ∇f:

∇f · 𝐮 = 0

then the directional derivative is zero.

Very common exam mistake: If the question gives a direction vector such as ⟨3,4⟩, do NOT use it directly. Normalize it first unless it is already a unit vector.

9.8 Divergence — Simple Revision

For quick exam purposes, remember divergence as the dot product of the del operator with a vector field.

∇ = 𝐢 ∂/∂x + 𝐣 ∂/∂y + 𝐤 ∂/∂z

If:

𝐅 = P𝐢 + Q𝐣 + R𝐤

then:

div 𝐅 = ∇·𝐅 = Px + Qy + Rz
Fast example: 𝐅 = x²𝐢 + yz𝐣 + 3z²𝐤.
∂(x²)/∂x = 2x
∂(yz)/∂y = z
∂(3z²)/∂z = 6z
div 𝐅 = 2x + z + 6z = 2x + 7z

Divergence vs. Directional Derivative

Directional derivativeDivergence
Usually starts with scalar fStarts with vector field 𝐅
Measures change of f in one directionMeasures spreading/convergence of 𝐅
D𝐮f = ∇f · 𝐮∇·𝐅
Result is scalarResult is scalar

📝 Practice Exam

Try these without looking at the answers. Click each question to reveal the solution.

Q1. Find the magnitude and unit vector of 𝐀 = ⟨2,−3,6⟩.

|𝐀| = √(4+9+36) = 7.

𝐀̂ = ⟨2/7,−3/7,6/7⟩.

Q2. Find 𝐀·𝐁 for 𝐀=⟨2,1,−3⟩ and 𝐁=⟨1,4,2⟩.

2(1)+1(4)+(−3)(2) = 2+4−6.

𝐀·𝐁 = 0, so they are perpendicular.

Q3. Find 𝐀×𝐁 for 𝐀=⟨1,0,2⟩ and 𝐁=⟨3,1,4⟩.

i: 0(4)−2(1)=−2

j: −[1(4)−2(3)] = 2

k: 1(1)−0(3)=1

𝐀×𝐁 = ⟨−2,2,1⟩.

Q4. Find the divergence of 𝐅 = x²y𝐢 + xy²𝐣 + z³𝐤.

∂(x²y)/∂x = 2xy; ∂(xy²)/∂y = 2xy; ∂(z³)/∂z = 3z².

∇·𝐅 = 4xy + 3z².

Q5. Find fx and fy for f=x²y+sin(xy).

fx = 2xy + y cos(xy).

fy = x² + x cos(xy).

Q6. Is f=x³+2x²y+xy²+y³ homogeneous? If yes, degree?

Every term has total degree 3.

Yes. It is homogeneous of degree 3.

Q7. Use Euler's theorem for f=x²+xy+y².

n=2, fx=2x+y, fy=x+2y.

xfx+yfy=2f.

Q8. Find the directional derivative of f=x²+y² at (1,2) in direction ⟨3,4⟩.

∇f=⟨2x,2y⟩ → at (1,2): ⟨2,4⟩.

Unit direction = ⟨3/5,4/5⟩.

D𝐮f = 2(3/5)+4(4/5)=22/5.

Q9. What is the maximum directional derivative of f=x²+y² at (1,2)?

∇f(1,2)=⟨2,4⟩.

Maximum = |∇f| = √20 = 2√5.

Q10. Find the direction of maximum increase of f=x²+3xy+y² at (1,2).

∇f=⟨2x+3y,3x+2y⟩.

At (1,2): ∇f=⟨8,7⟩.

Direction = ⟨8,7⟩ (or unit direction ⟨8,7⟩/√113).

🚨 Last-Minute Exam Traps

  • Dot ≠ cross: dot gives a scalar; cross gives a vector.
  • Cross product order matters: 𝐀×𝐁 = −𝐁×𝐀.
  • j sign: determinant expansion has a minus on the j term.
  • Directional derivative: normalize the direction vector first.
  • Gradient: ∇f uses partial derivatives of a scalar function.
  • Divergence: ∇·𝐅 uses matching components: x with P, y with Q, z with R.
  • Euler theorem: only use it after confirming homogeneity and its degree.
  • Partial derivative: all other independent variables are treated as constants.
